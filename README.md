## Instalasi

gampang aja tinggal

```sh
git clone https://github.com/mroczect/pbl-trpl-106-frontend.git
cd pbl-trpl-106-frontend
```

nah kalau udah tinggl 
```sh
npm install
composer install
```

kalau udha langsung aja run

```sh
npm run dev
```

selesai barang itu.
